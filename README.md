# 🐍 Lernaean

Agentic red-team framework. Multi-LLM backend, auto-installs missing tools, terminal-native.

## Install

### Linux / Termux / Kali
\`\`\`bash
git clone https://github.com/YOURUSERNAME/lernaean.git
cd lernaean
bash install.sh
\`\`\`

### Windows
\`\`\`cmd
git clone https://github.com/YOURUSERNAME/lernaean.git
cd lernaean
install.bat
\`\`\`

## Run
\`\`\`bash
python lernaean.py
\`\`\`

## Providers Supported
- OpenAI
- Anthropic
- Gemini
- Groq
- OpenRouter (uncensored models)
